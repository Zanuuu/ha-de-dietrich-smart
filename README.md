# De Dietrich Smart for Home Assistant

Custom integration for De Dietrich boilers with a **SMART TC°** thermostat (tested on an
EMC-S 24/28 MI), through the BDR Thermea cloud used by the De Dietrich and Remeha Home apps.

> Work in progress (v1). Installation, configuration and the migration from the former
> `ancienne application` application are documented once v1 is complete.

## Installation (HACS)

1. HACS → three-dot menu → **Custom repositories** → `https://github.com/Zanuuu/ha-de-dietrich-smart`,
   category **Integration**.
2. Install, restart Home Assistant, then *Settings → Devices & services → Add integration →
   De Dietrich Smart*.
